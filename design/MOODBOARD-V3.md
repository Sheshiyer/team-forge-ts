# Team Forge V3 Moodboard - Command Cortex

**Direction:** Abstract tactical neural tissue map for a Tauri/macOS agentic company OS  
**Status:** Concept moodboard generated for review  
**Core rejection:** Not a SaaS dashboard, no left menu drawer, no rectangular card grid

## Concept

Team Forge becomes **Command Cortex**: a powerful biological war-room for commanding AI agents through the living nervous system of the company.

The product should feel like a crisp engineered neural tissue map, not literal organic sci-fi and not admin software. The founder is not browsing pages. The founder is observing operational signals, tracing agent movement, and intervening surgically when needed.

## Home Screen

The first prototype should be the **Mission Cortex** home screen.

- Center: mission nucleus showing current operational state.
- Branches: clients, projects, issues, agents, humans, routines, and knowledge connected as synaptic pathways.
- Agents: moving pulses traveling through the network.
- Risk: amber/red inflammation around unstable branches.
- Navigation: floating lens rail, not sidebar.
- Commands: keyboard-first intent bar and contextual command ring.
- Context: tactical membrane attached to selected nodes, not dashboard cards.

## Buildable Primitives

This should stay ambitious visually but practical technically.

- SVG neural field with Bezier paths and node glyphs.
- CSS/SVG animated signal particles along paths.
- React overlay controls for lens rail and command bar.
- Radial command ring with positioned buttons.
- Clipped polygon tactical membranes using CSS `clip-path`.
- macOS/Tauri titlebar safe zone and bottom runtime strip.
- No WebGL required for MVP.

## Visual Rules

- No SaaS dashboard grammar.
- No permanent sidebar.
- No KPI card grid.
- No generic rectangular cards.
- Use neural branches, node glyphs, signal paths, membranes, command rings, and tactical labels.
- Every animation should mean something: flow, confidence, risk, pending judgment, blocked path, or handoff.
