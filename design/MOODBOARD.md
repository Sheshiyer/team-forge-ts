## Design Philosophy

**Core Aesthetic:** Bloomberg Terminal × Linear × SpaceX Mission Control

Team Forge is NOT a typical SaaS dashboard. It's a **Founder Command Center** - a dense, information-rich control surface for orchestrating an entire organization. The design prioritizes:

1. **Information Density** - Lots of data, elegantly displayed
2. **Command Authority** - Professional, authoritative, sophisticated
3. **AI Orchestration** - Agents as first-class citizens alongside humans
4. **Multi-Integration Unity** - Single view across Paperclip, Clockify, Huly, GitHub, Slack
5. **Role-Based Perspective** - Executive/PM/Developer lenses on same data

## Visual Language

### Color Palette

| Role | Color | Hex | Usage |
|------|-------|-----|-------|
| **Backgrounds** |
| Void | Near black | `#0a0a0f` | App background, deep base |
| Panel | Dark slate | `#12121a` | Cards, panels |
| Surface | Mid slate | `#1a1a24` | Elevated surfaces |
| Elevated | Light slate | `#222230` | Hover states, modals |
| **Status Colors** |
| Healthy/Success | Emerald | `#10b966` | Agent runtime OK, project on track |
| Active/Primary | Electric Blue | `#3b82f6` | Primary actions, navigation, focus |
| Warning/Attention | Amber | `#f59e0b` | Needs attention, review queue |
| Critical/Blocked | Rose | `#f43f5e` | Blocked items, escalations, open issues |
| Paused/Inactive | Slate | `#64748b` | Paused projects, offline agents |
| Completed | Purple | `#8b5cf6` | Finished items, archived |
| **Text** |
| Primary | Pure white | `#fafafa` | Headers, important text |
| Secondary | Light gray | `#a1a1aa` | Body text, descriptions |
| Muted | Medium gray | `#52525b` | Labels, timestamps |
| Disabled | Dark gray | `#3f3f46` | Disabled states |

### Typography

| Element | Font | Weight | Size | Color |
|---------|------|--------|------|-------|
| Display | Inter | Bold | 32px | Primary |
| H1 | Inter | Semibold | 24px | Primary |
| H2 | Inter | Medium | 18px | Primary |
| H3 | Inter | Medium | 14px | Secondary |
| Body | Inter | Regular | 14px | Secondary |
| Label | Inter | Medium | 11px | Muted, all caps |
| Micro | Inter | Regular | 12px | Muted |
| Data/Numbers | JetBrains Mono | Medium | 16px | Primary |
| Agent Names | JetBrains Mono | Semibold | 14px | Status-colored |
| Code | JetBrains Mono | Regular | 13px | Primary/Context |

### Geometric Principles

- **No rounded corners** - Sharp geometric forms throughout
- **Left-border accents** - Colored bars indicate status/category
- **Subtle glows** - Soft glow on accent colors for depth
- **Grid overlay** - Subtle grid suggests precision
- **Dense but organized** - Information hierarchy over whitespace
